# Security

bugbout runs coding agents and the code they write, so its sandboxing matters. If you
find a way for an agent or its tests to write outside the directories it was given,
reach the network when it should not, or see a task's hidden tests, please report it
privately through GitHub's [private vulnerability reporting](https://github.com/Keerthirajan58/bugbout/security/advisories/new)
rather than in a public issue.
